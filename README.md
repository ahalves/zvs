# TPS2814-based ZVS Driver
A ZVS driver based around the TPS2814 MOSFET driver, which switches them rapidly keeping them out of their linear region. circuit adapted from u/McSlayR01, upgraded to allow for more current, and higher input voltage range (13-80V) input thanks to the XL7015 buck converter.
